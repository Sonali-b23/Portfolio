BRAIN TUMOR CLASSIFICATION USING CNN

Problem

Accurate classification of brain tumors from MRI scans is critical yet challenging, with manual analysis being time-intensive and susceptible to human error.

Approach

  • Preprocessing: Employed OpenCV and NumPy for image enhancement and normalization.
  • Model Development: Designed a Convolutional Neural Network (CNN) architecture using PyTorch.
  • Data Exploration: Conducted comprehensive exploratory data analysis to fine-tune hyperparameters.
  • Evaluation: Assessed model performance through metrics including accuracy, precision, and recall.

Results

  • High Accuracy: Achieved over 92% classification accuracy on unseen test data.
  • Reliable Detection: Effectively differentiated between tumor and healthy tissue images.
  • Version Control: Managed source code and collaboration through GitHub.

This project demonstrates the potential of deep learning models to support radiologists by enhancing diagnostic speed and accuracy.

SOLAR POWER PREDICTION USING ANFIS AND MPPT

Problem

Solar power output fluctuates due to changing weather conditions, resulting in inefficiencies and unpredictable energy generation.

Approach

  • Data Acquisition: Collected comprehensive datasets on solar panel performance and meteorological variables.
  • Data Processing: Utilized Pandas for cleaning and preparing structured data for modeling.
  • Modeling: Implemented Adaptive Neuro-Fuzzy Inference System (ANFIS) regression combined with MPPT algorithms for optimized prediction.
  • Validation: Evaluated predictive accuracy and MPPT effectiveness under dynamic environmental scenarios.

Results

  • Improved Efficiency: Enhanced solar panel output through real-time MPPT control integration.
  • Accurate Forecasting: Delivered reliable solar power predictions leveraging weather data inputs.
  • Robust Documentation: Maintained thorough code documentation and version control via GitHub.

This work highlights the effectiveness of hybrid intelligent systems in maximizing renewable energy utilization.

DESIGN AND ANALYSIS OF ANFIS-CONTROLLED MPPT FOR SOLAR PV SYSTEMS
