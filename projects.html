Twitter API Semantic Search

Overview (Python)

A semantic search engine designed specifically for the Twitter API Postman documentation. It enables users to intelligently query the API documentation and retrieve the most relevant endpoints and descriptions using advanced sentence embeddings.

Key Features

  • Implementation of Sentence Transformers to convert text into embeddings.
  • Vector similarity search for fast and highly accurate endpoint retrieval.
  • Streamlines API integration for developers by allowing natural language queries.

Brain Tumor Classification CNN

Overview (Python & PyTorch)

A Convolutional Neural Network (CNN) based brain tumor classification project built with PyTorch, operating on MRI images. Implements binary classification to accurately distinguish between tumor and non-tumor scans.

Key Features

  • Custom CNN architecture designed in PyTorch for high-precision image classification.
  • Includes model evaluation, checkpointing to save state, and visualization of loss/accuracy curves.
  • Ideal for assisting medical professionals in rapid diagnostic analysis.
